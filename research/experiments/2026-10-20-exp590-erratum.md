# Errata EXP-590 — clasificación Currier contaminada por $Q

Fecha: 20-10-2026  
Estado: artefacto histórico **INVALID_FOR_CLAIM** para resultados por clase Currier; reproducción corregida **REPRODUCED** en GitHub Actions run [39490514535](https://github.com/kyrian20/voynich-autoexploration/actions/runs/39490514535). No se declara `VALIDATED`.

## Qué ocurrió

La versión original de scripts/exp590_daiin_position.py obtenía la etiqueta de clase con la variable IVTFF $Q. En IVTFF, $Q identifica el cuaderno/quire; la lengua Currier se representa mediante $L=A/B. Por tanto, la distribución A/B/unknown del JSON y el informe originales de EXP-590 no representa la clasificación Currier correcta.

## Reproducción corregida

El workflow autónomo ejecutó el script corregido y guardó salidas separadas: [`2026-10-20-exp590-corrected-L-metadata.json`](2026-10-20-exp590-corrected-L-metadata.json) y [`2026-10-20-exp590-corrected-L-metadata.md`](2026-10-20-exp590-corrected-L-metadata.md). La ejecución reportó 4.188 líneas, 32.732 tokens y 726 ocurrencias de `daiin`; la distribución ahora es A=440, B=278 y unknown=8. El total global coincide con el histórico; la asignación por clase cambia porque se corrigió la variable. Esto acredita reproducción de la salida con la regla `$L`, no validación estadística ni desciframiento.

## Archivo histórico preservado

Antes de la reproducción corregida se copiaron los artefactos originales, sin modificarlos, a [`archive/2026-10-20-exp590-original-invalid-Q-metadata.json`](archive/2026-10-20-exp590-original-invalid-Q-metadata.json) y [`archive/2026-10-20-exp590-original-invalid-Q-metadata.md`](archive/2026-10-20-exp590-original-invalid-Q-metadata.md). Los originales en las rutas históricas se mantienen separados de la copia archivada; la reproducción corregida debe escribir a nombres distintos.

## Alcance del defecto

- No utilizar la tabla por clase del resultado original de EXP-590 para comparar Currier A frente a B.
- Los conteos globales de tokens y de posición no dependen directamente de la clase Currier; aun así, se deben regenerar al reproducir el script para comprobar que el código y la fuente son idénticos.
- El defecto no debe ocultarse sobrescribiendo el resultado histórico. El JSON/Markdown original se conserva para trazabilidad.
- El script se corrigió para usar el parser común parse_currier_language, que solo lee $L.
- Se añadieron pruebas de regresión que cubren cabeceras con $Q y $L contradictorios y la clasificación unknown cuando falta $L.
