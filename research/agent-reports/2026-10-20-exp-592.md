# EXP-592 — Exploratory max-T correction for line-initial EVA tokens

Fecha: 2026-10-20

- Fuente: `data/transcriptions/eva_zl3b.txt`
- Blob SHA: `2a4533ab9bdfa85db9bad602d590978953055df1`
- Only IVTFF text rows matching ^<f[0-9]+[rv]\.[^>]*>; remove angle-bracket annotations, square-bracket uncertainty blocks, and brace blocks; split on period/comma/whitespace; retain alphabetic tokens. This deliberately strict parser is not identical to the earlier EXP-591 parser; do not compare raw counts directly.
- Líneas de texto: 4188; tokens: 32678; vocabulario: 6481; candidatos (frecuencia ≥50): 104.

## Método
Within each line, the null selects one token uniformly from its observed positions, preserving line token multiset and length. For each candidate, z=(observed initial count - sum per-line c_t/L)/(sqrt(sum per-line p_t(1-p_t))). max-T statistic is maximum z over all 104 candidates. 5000 simulations, deterministic LCG seed 20261020; empirical p=(exceedances+1)/(B+1).

## Limitaciones
- Exploratory, not a decryption or semantic claim.
- The candidate threshold and max-T family are defined here but the hypothesis was motivated by prior analyses; this is not a pristine preregistered test.
- Lines are not independent experimental units; the null conditions on each line and tests only token position.
- At 5,000 simulations the smallest attainable corrected empirical p is 1/5,001 ≈ 0.00020.
- Parser differs from EXP-591, so compare effect direction rather than raw counts.

## Interpretación provisional
`daiin` muestra un exceso de comienzos de línea frente al nulo condicionado a cada línea, pero no es el token con el mayor residuo estandarizado: varias formas raras (aunque con frecuencia ≥50) están más concentradas al inicio. La corrección max-T indica que la búsqueda entre múltiples candidatos es importante. No inferimos significado ni desciframiento. Siguiente paso: repetir con una partición definida por folios, reportar estabilidad por folio y estratificar por Currier A/B usando etiquetas verificadas, con un parser único versionado.
