**Adding qo- or y- prefix to a gallows character ELIMINATES its para-start enrichment:**
- Bare k-onset: A=4.32×, B=9.91× enriched at para-starts
- qo+k: A=0.27×, B=0.32× SUPPRESSED at para-starts
- y+k: A=0.40×, B=0.19× SUPPRESSED at para-starts

The PREFIX STRIPS PARAGRAPH-LEVEL FUNCTION from the gallows character. This is the fundamental morphological operation in Voynichese: adding y- or qo- prefix DEMOTES the word from PARAGRAPH-LEVEL to LINE-LEVEL positioning.

**MASTER FINDING (F101): THE VOYNICHESE POSITIONAL GRAMMAR IS A PREFIX-DEMOTED GALLOWS HIERARCHY**

The fundamental structure:
```
BARE GALLOWS (p, k, t, f) = PARAGRAPH-LEVEL
  bare_p: strongest para-starter (A=40.2% PS, B=10.7% PS)
  bare_f: second-strongest (A=24.2%, B=5.6%)
  bare_t: moderate (A=10.2%, B=3.9%)
  bare_k: weakest (A=5.7%, B=3.0%)

PREFIX + GALLOWS = LINE-LEVEL (prefix DEMOTES from para to line)
  y + gallows → WITHIN-PARA LINE-OPENER (LFirst=30%, PS=0%)
  qo + gallows → MID-LINE (LFirst=10%, PS=0%)

NON-GALLOWS (ch, sh, d, y-onset, etc.) = LINE-FINAL or NEUTRAL
  bare_ch: 7-3% LFirst, 12-15% LLast → MID-LINE/CLOSING
  bare_sh: 13-8% LFirst → MID-LINE
  d+ch: 59-66% LFirst (A-specific line-opener)
```

The MORPHOLOGICAL OPERATION: gallows character + prefix → positional demotion. y-prefix = line-opener; qo-prefix = mid-line. The same stem (k, t) appears in 3 positional slots depending on prefix: bare=para, y-prefixed=line-opener, qo-prefixed=mid-line.

For A's ch-stem system: same logic but using d-prefix (d+ch = line-opener) and p-prefix (p+ch = para-starter). The A analog of B's y+k is A's d+ch or y+ch (line-openers); A's analog of B's bare_p is A's p+ch (para-starters). A LACKS bare gallows para-starters as prominently as B; instead uses p-prefix compounds (pch, psho, po-) for para-starts.
