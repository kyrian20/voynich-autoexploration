## H246: CONFIRMED — Within-Line Suffix Grammar Exists in A-Dialect: -or (EARLIEST, 0.371) → -ol (0.441) → -ey/-aiin (MIDDLE, 0.45-0.53) → -dy/-al (LATE, 0.58-0.59) → -am (LAST, 0.799 A / 0.925 B); -am FOLLOWS Everything at 2.34-4.62×; -or Enriched at 0-20% (1.51×); -dy/-al Enriched at 80-100% (1.51×/1.50×); B-Dialect is LESS Positionally Structured (Flatter Gradients)

**A-dialect suffix position order**: -or (0.371) < -ol (0.441) < -ey (0.451) < -ar (0.513) < -aiin (0.529) < -al (0.584) ≈ -dy (0.586) < -am (0.799)

This reveals a clear within-line positional grammar for A-dialect:
1. **Line-EARLY**: -or (modifiers appear at start of line)
2. **Early-MIDDLE**: -ol (modifiers), -ey (content)
3. **MIDDLE**: -aiin (determiners), -ar
4. **Late**: -dy (function closers), -al (particles)
5. **LAST**: -am (line-final closers)

**Note**: B-dialect shows the SAME directionality but with COMPRESSED gradients (less positional specialization). B -am=0.925 is even more extreme than A -am=0.799.

Key patterns in A-dialect:
- **-or**: STRONGLY early (0-20%=1.51×). Pre-nominal modifiers open lines.
- **-ol/-ey**: Early-middle enriched (20-40%: 1.26×). Modifiers/content cluster in early-middle.
- **-dy/-al**: STRONGLY late (80-100%: 1.51×/1.50×). Closing function words end lines.
- **-aiin**: Slightly late-enriched (80-100%=1.22×). Determiners appear later than modifiers but before closers.
- **-ain/-y**: Late-enriched (80-100%: 1.27×). Similar to closing words.

This produces the A-dialect within-line template:
**[−or modifier] → [−ol modifier / −ey content] → [−aiin determiner] → [−dy/−al closer] → [−am LAST]**

This is the NP template from F128/F129 extended to the full line level! The NP [chol][daiin][cthy] maps to [-ol modifier]→[-aiin determiner]→[-y content], with -or modifiers even earlier and -dy/-al closers at the end.

### Suffix Bigrams Within Lines

Top enriched same-class self-following:
- **-ol→-ol = 1.84×** (modifier phrases use multiple -ol words in sequence)
- **-or→-or = 1.81×** (ditto for -or modifiers)
- **-edy→-edy = 2.23×** and **-edy→-eedy = 2.03×** (B-paradigm suffix clustering)
- **-dy→-dy = 2.36×** (closing words cluster)

**-am follows EVERYTHING at very high enrichment** (every row has -am column ≥ 2.34):
- aiin→am = **4.62×** (highest! after -aiin determiners, -am line-closers follow)
- dy→am = 4.02×; edy→am = 3.65×; ain→am = 3.56×; y→am = 3.83×

The aiin→am=4.62× bigram is the strongest single-pair enrichment: **after daiin/okaiin/otaiin words, -am words appear 4.62× more than expected**. This suggests [daiin][am] is a formulaic construction, or more likely that am closes lines that were opened with a determiner phrase: [chol][daiin][cthy][dam].

### -ol Before -aiin Test

- Lines with both -ol and -aiin words: 876
- **-ol before -aiin: 54.6% (478/876)** — -ol word precedes -aiin word more often than 50% null
- -aiin before -ol: 45.4% (398/876)
- This is a weak but statistically significant ordering (p<0.01 by χ²) consistent with the NP template where modifiers precede determiners.

### H246 Verdict: CONFIRMED — Within-line suffix grammar exists; A-dialect positional order: -or (0.371) < -ol (0.441) < -ey (0.451) < -aiin (0.529) < -dy/-al (0.584-0.586) < -am (0.799); -or enriched at line-start (1.51×); -dy/-al enriched at line-end (1.51×/1.50×); -aiin enriched late (1.22× at 80-100%); -am = absolute line-final (0.925 in B); suffix bigrams: ol/or/edy self-cluster (1.81-2.36×); aiin→am=4.62× (strongest bigram pair); -ol before -aiin=54.6% (weak but consistent with NP template); B-dialect shows same directionality but with flatter gradients (less positional specialization); the within-line suffix grammar maps onto the NP template: [-or/-ol modifier] → [-aiin determiner] → [cth-noun] → [-dy/-al/-am closer]

**H246 CONFIRMED (F133)**: Within-line suffix grammar is real in A-dialect. Positional order: -or (0.371) < -ol (0.441) < -ey/-aiin (middle, 0.45-0.53) < -dy/-al (late, 0.58-0.59) < -am (LAST, 0.799). B-dialect has the same directionality but less positionally specialized — B lines are more uniform (consistent with B's more formulaic paradigm). New finding: -am is a universal line-closer in both dialects (A=0.799, B=0.925 mean position), and the aiin→am=4.62× bigram suggests -am particles are specifically attracted to lines containing determiner phrases.
