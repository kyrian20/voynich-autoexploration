### H075 Verdict: PARTIALLY SUPPORTED — cross-dialect, not B-specific

The B two-marker system (p-onset para-start / y-initial continuation) exists but is a general Voynichese feature:
- p-onset is a cross-dialect para-start marker (A: 7.38×, B: 2.80×)
- y-initial is a cross-dialect continuation marker (0.00×/0.28× at PS; 1.12×/1.05× at continuation)
- B's pch subtype (17×) and A's p_other (18.21×) are both specializations of the cross-dialect p-onset system

### Key Findings on s vs d

**s-initial words are line-INITIAL biased (4.61×) but NOT line-final biased (0.95×)** — opposite of the d-initial pattern (2.43× line-first AND 1.42× line-last). Despite sharing a suffix profile (both aiin-dominant: s=-aiin=20.6%, d=-aiin=20.8%), s and d have different positional grammar in B.

s and d differ from each other: **d is enriched at BOTH edges; s is exclusively line-initial**. Top s-words in B: saiin (80), sain (53), sar (40), sol (30), sal (25), sor (24) — these are all simple stem+suffix forms that appear at line openings.

### H074 Verdict: NOT SUPPORTED (s and d have different positional grammar despite similar suffixes)

s is NOT positionally equivalent to d. s-initial marks line-INITIAL positions (4.61×) exclusively, while d-initial marks BOTH edges. The shared aiin-dominant suffix reflects a common morphological paradigm class but different syntactic deployment.

## Complete Currier B Onset Positional Grammar (H076 resolved simultaneously)

The onset class positional analysis reveals a complete positional grammar for Currier B:

**Line-initial biased onsets** (structural/position-marking words):
- p (6.34×): para-start marker (F070)
- s (4.61×): line-continuation opener (like y-initial but via onset)
- y (3.41×): line-continuation marker (F061)
- t (3.38×): continuation/opener

**Both-edges biased**:
- d (2.43× first, 1.42× last): appears at both line-first and line-last (complex positional role)

**Line-final biased**:
- o (1.24× last): slightly prefers line endings

**Medial biased** (avoid both edges):
- ch (0.17× first, 0.90× last): strongly medial
- sh (0.42×/0.42×): avoids both edges
- qo (0.64×/0.60×): slightly medial

This positional grammar maps onto the 4-class onset taxonomy (F068):
- {p}: para-start class
- {s, y, t}: line-opener/continuation class
- {d}: edge-adjacent class
- {ch/sh, qo}: medial class
- {k}: neutral (baseline)
- {o}: slightly line-final

## Combined Finding (F071)

p-onset is a cross-dialect para-start marker (A: 7.38×, B: 2.80× overall; pch subtype 17× in B). The B two-marker positional system (p-onset para-start / y-initial continuation) is a general Voynichese feature, not B-specific. Currier B onset class positional grammar is a complete system: p (6.34× line-first = para-start); s/y/t (3-5× line-first = continuation/opener); d (2.43× first AND 1.42× last = edge-adjacent); ch/sh/qo (0.17-0.64× first = medial). s-initial is NOT equivalent to d-initial despite similar suffix distributions: s is exclusively line-first biased (4.61×); d is biased at both edges. The onset positional grammar in B maps directly onto the 4-class taxonomy from F068, with {p} = structural, {s/y/t} = continuation, {ch/sh/qo} = medial, {d} = edge-marker, {o} = line-final biased.
