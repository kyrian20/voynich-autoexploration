# exp_590 — Section-range stratification of daiin

**Question:** does the exp_589 Currier-B line-initial excess persist across coarse manuscript folio ranges, or is it driven by one range?

This is a sensitivity analysis, not an independent transcription replication. It reuses ZL3b and exp_589's preprocessing rules. It does not change the primary exp_589 result.

## Method
- Same body-locus rule: `^[+*@]?P`; same conservative token cleanup; lines need at least two tokens.
- Separate Currier A and B within coarse bins: f001–f066, f067–f073, f074–f084, f085–f102, f103–f116.
- These bins are inherited from an earlier project script and are **only folio-number proxies**, not definitive codicological section assignments.
- 2,000 within-line position draws per eligible stratum, fixed seeds. Expected first count conditions on the token inventory and length of each line.
- All strata are emitted; small strata are descriptive only where appropriate. The primary Currier-B range family uses Holm correction across the five B strata; the Currier-A family is secondary and corrected separately.

## Status
Results are generated by GitHub Actions and committed to `results.json`. Inspect `result.md` for interpretation and limitations. This experiment checks concentration across rough folio ranges and does not establish word meaning.
