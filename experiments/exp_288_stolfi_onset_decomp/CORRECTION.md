# Correcciones vigentes de EXP-288

La [adjudicación reproducible](../../research/maintenance/2026-10-22-claim-link-adjudication/REPORT.md) corrige dos interpretaciones del informe histórico:

- Los 87.754 registros del control Cicero proceden de un texto bilingüe latín+inglés y una descomposición distinta de EVA; no constituyen un control latino monolingüe comparable.
- El rango entre entropías condicionales de onset no mide información mutua. Los valores 0,678/0,789 bits no justifican afirmar una reducción de incertidumbre de aproximadamente 0,7 bits. La información mutua real no se ha calculado en esta revisión.

Los originales se conservan congelados. No se invalidan automáticamente las tablas internas Voynich; tampoco se declaran validadas.
