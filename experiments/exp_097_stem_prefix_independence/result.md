### B Dialect: 16 Stems in ALL 4 Prefix Classes

In B, 16 stems appear with all 4 classes (p, y, d, bare), including: chedy(29/10/23/424), chedar(10/2/1/25), chdy(7/1/7/106), cheol(6/4/7/78). B has MORE multi-prefix stems than A — B's ch-stem vocabulary is more flexible.

### Interpretation: Frequency Effect, Not Categorical Exclusion

The 87.8% "exclusive" stems are NOT semantically specialized to one prefix — they simply have too few tokens to observe them in all positional contexts. Evidence:
1. High-frequency stems (chol=279, chor=238) appear in ALL prefix classes
2. Low-frequency stems (1-2 tokens) can only appear once, so statistically must appear in 1 class
3. There is a continuous PRODUCTIVITY GRADIENT — more frequent stems appear in more prefix classes
4. The SAME stems (chol, chor, chey) are the top-frequency forms for EVERY prefix class

**This is exactly like natural language morphology:** high-frequency verbs are fully conjugated (appear in all tenses/moods); rare verbs have few attested forms. The pattern is STATISTICAL, not lexical.

### H178 Verdict: PARTIALLY CONFIRMED — The Core Productive ch-Stems (chol, chor, chy, cheor, cheey) Appear Across ALL Prefix Classes; the 87.8% "Exclusive" Stems Are Frequency-Limited (Too Rare to Observe in All Contexts); The Pattern Is Consistent With Productive Stem × Prefix Combinatorics — Same Stems Appear with Para-Prefix (p+ch), Line-Opener Prefix (y/d+ch), and Bare Mid-Line Form

## H179: f+ch Cross-Dialect Asymmetry Is REAL — A Uses f+ch in Herbal Para-Starts; B Uses f+ch in Stars as Mid-Line

### f+ch Distribution by Section

| Section | A tokens | A PS count | B tokens | B PS count |
|---------|----------|-----------|----------|-----------|
| herbal | 11 | **3** (27%) | 6 | 0 |
| pharma | 2 | 0 | 2 | 0 |
| stars | 0 | 0 | **19** | 0 |
| cosmo | 0 | 0 | 3 | 0 |

**The f+ch asymmetry is SECTION-LEVEL:**
- In A (herbal-dominated), f+ch appears in herbal A with para-start usage
- In B (stars-heavy), f+ch concentrates in stars section with ZERO para-starts

In B, the top f+ch word is **fchedy** (9 tokens, all in stars) — this is f+ch+EDY, a B-type suffix. The B f+ch forms are B-dialect words that happen to start with f+ch but function as normal mid-line vocabulary in the stars section.

In A, f+ch forms are: fcholdy, fcheody, fchodaiin, fchol, fcholy, fcho, fchey — A-type ch-stem forms.

**Mechanism:** The f-gallows in B is used differently than in A. In A, f-gallows creates para-starters (like p-gallows). In B, f+ch words occur in specific sections (stars) as content words with B-type suffixes, losing the para-start function. This is a genuine DIALECT DIFFERENCE in how the f-gallows is recruited for the positional grammar.

### H179 Verdict: CONFIRMED — f+ch Cross-Dialect Asymmetry Is Real and Section-Driven: A Uses f+ch for Herbal Para-Starts; B's f+ch Concentrates in Stars Section as Mid-Line Content (B-type -edy Suffixed Forms); This Is a Dialectal Difference in Which Gallows Character Serves Para-Level Function
