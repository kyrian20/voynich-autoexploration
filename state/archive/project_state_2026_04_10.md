# Project State — Voynich Cryptanalyst
**Date**: 2026-04-10
**Prepared by**: Autonomous agent synthesis (Sonnet 4.6)
**Purpose**: Re-orientation document for returning investigator; foundation for methodology paper draft

---

## 1. Project Overview

This project is an attempt to apply a structured autonomous-agent research loop to the Voynich Manuscript — Beinecke MS 408, the fifteenth-century illustrated codex whose script has never been convincingly deciphered and whose contents remain unknown. The central question is whether computational statistics can meaningfully advance theory discrimination beyond what the existing literature has established: not decipherment, but a defensible narrowing of the hypothesis space. The project is explicitly not trying to solve the manuscript; it is trying to establish what classes of generation mechanisms are and are not consistent with the manuscript's statistical structure.

The approach is a multi-phase autonomous agent loop with human oversight checkpoints. A Sonnet-class agent handles the primary experimental work — literature review, experiment design, code execution, result synthesis — while an Opus-class agent performs independent meta-review at the end of each phase. Human decisions are required for phase transitions, scope changes, and any "pause condition" triggered when results are ambiguous or potentially methodologically compromised. This division was chosen because it separates production from review, reducing the risk of the primary agent developing blind spots or compounding errors across experiments. The meta-review process has been substantively valuable: it caught a statistical artifact (the lags 10-12 MI overclaim) and a calibration issue (the position-sensitive cipher's target-awareness) that the primary agent did not flag.

The project is organized into three parallel phases: Librarian (literature review and knowledge base construction), Botanist (visual embedding comparison of VMS botanical illustrations against medieval herbal manuscripts), and Cryptanalyst (statistical hypothesis testing). All three phases are underway, but the Cryptanalyst has progressed furthest and has produced the project's main findings to date.

## 2. Infrastructure Built

**The Librarian knowledge base** lives at `~/voynich-kb/` and is structured as a three-layer system: a SQLite registry (`registry.db`) tracking every source encountered with lifecycle status (discovered → summarized → archived), a `summaries/` directory of structured markdown summaries with YAML frontmatter, and an `archives/` directory holding full source content (PDFs, HTML snapshots, datasets). Sources are organized by a breadth-first citation graph rooted at hand-selected depth-0 seeds; each source records its discovered-from parent and cite count. The registry currently holds 123 sources: 116 summarized, 6 pending, 1 failed due to access restrictions. Depth ranges from 0 (35 seeds) to 5. The state directory at `~/voynich-kb/state/` holds agent working memory including `failed_approaches.md`, `open_questions.md`, a coverage report, and an iteration log. The KB also maintains per-folio cross-reference files for the Botanist and archived datasets for the Cryptanalyst.

**The Cryptanalyst experiment framework** lives at `~/voynich-cryptanalyst/` and is organized around numbered experiment directories (`exp_001/` through `exp_179/`), each containing `script.py`, `result.md`, and where applicable a `data/` subdirectory with raw outputs. The corpus is the EVA ZL3b IVTFF transcription at `data/transcriptions/eva_zl3b.txt`. A `state/` directory holds the continuously-updated synthesis documents: `working_model.md` (characterization findings), `working_position.md` (theory discrimination verdicts), `findings.md` (the canonical finding registry), `hypothesis_backlog.md`, `open_questions.md`, `synthesis_audit.md`, and the two Opus review documents. The entire project history is in git, providing reproducibility: every committed result is recoverable and every script is versioned alongside the result it produced.

**The Botanist phase infrastructure** lives at `~/voynich-kb/botanist/` and includes a Python virtual environment with PyTorch and HuggingFace transformers (DINOv2 verified running on Apple Silicon MPS), a `STRATEGY.md` describing the four-pass embedding protocol, and a `classify_folios.py` script used for VMS metadata classification. Downloaded image data: 209 VMS folios from Beinecke IIIF (including split foldout panels), 513 Manfredus herbal images from Gallica IIIF, a partial Vienna Dioscorides set (65 of 162 images from Wikimedia Commons), and a partial Carrara Herbal set (severely limited by British Library IIIF infrastructure being offline since a 2023 cyberattack). Embedding extraction has not yet been run.

**The Sonnet/Opus division of labor** is: Sonnet designs and runs all experiments, writes summaries and synthesis documents, and manages the git history. Opus performs independent review of synthesis documents at phase boundaries, reviewing the primary agent's work without access to the primary agent's intermediate reasoning. The two reviews conducted so far (after Phase 2 and after Phase 3) have each produced substantive corrections to the synthesis. The meta-review is not a rubber stamp; both reviews found specific errors or overstatements that changed the framing of the results.

## 3. The Librarian Phase

The Librarian phase ran a breadth-first citation traversal starting from 35 hand-selected depth-0 seeds representing the major published positions in Voynich research. Seeds included foundational sources (D'Imperio's 1978 monograph, Currier's 1976 language analysis), recent computational work (Bowern and Lindemann's entropy analysis, Timm and Schinner's self-citation model), specific cipher proposals (Greshko/Naibbe tarocchi cipher, Rugg's hoax hypothesis, Crowe's Arabic hypothesis), transcription resources (EVA standard, IVTFF format), and the Beinecke digital facsimile. From these seeds, the traversal discovered and summarized sources to depth 5, with the density dropping naturally at greater depth (35 at depth 0, 40 at depth 1, 18 at depth 2, 18 at depth 3, 11 at depth 4, 1 at depth 5).

The KB construction also involved substantial reclassification work early in the phase: source metadata was corrected for several entries (dates, titles, URLs), and a typed-edge schema was implemented to distinguish citation relationships from hypothesis-dependency relationships and dataset-provenance relationships. The typed edges allow downstream query by relationship type — finding all sources that depend on a given dataset, or all sources that cite a given cipher proposal — rather than flattening all relationships into a generic citation graph.

The KB is currently in a "queryable reference" state. The `registry.db` supports SQL queries against the full source graph. The summaries include machine-parseable YAML frontmatter with fields for hypothesis type, verdict, citation count, and folio cross-references. The Cryptanalyst phase consumed the KB primarily through the `archives/datasets/` directory (EVA transcriptions, Stolfi vocabulary analysis, Timm and Schinner algorithm description) rather than through live queries; the full KB query capability has not yet been exercised by a downstream agent.

One technical failure worth documenting: an early experiment with a cron-based autonomous Librarian loop (running at fixed intervals via the Claude Code cron system) was abandoned after the loop failed to maintain coherent state across invocations. The problem was context management across sessions — the cron job would restart without access to the prior session's working memory, leading to duplicate discovery and inconsistent state. The current approach is session-based: the Librarian runs in a single session with full context, then commits state to git, and resumes from git state at the start of the next session.

## 4. The Cryptanalyst Phase: Characterization

The first 169 experiments (roughly) constituted a characterization phase: mapping the statistical properties of Voynichese without yet testing theories against those properties. The experiments covered onset-class distributions (initial character clusters), suffix paradigm structure, positional enrichment (which character classes prefer which positions within a line), cross-dialect comparison (Currier A versus B), self-succession rates (whether word classes tend to follow themselves), bigram and trigram patterns, word-length distributions, type-token ratios, and mutual information structure at different lags. The corpus parsing infrastructure went through several iterations, fixing bugs in the dot-separated word format and the locus parsing (the ZL3b transcription format uses `<fN.lineN,@Ptype>` locus strings that required non-obvious parsing).

Honestly, most of the first 169 experiments rediscovered results that are already in the literature. This is intentional and important for methodology validation: if a fresh computational analysis of the same corpus produces different numbers than the established literature, something is wrong with either the analysis or the source. The major findings that are genuinely established in prior work — the Currier A/B split, the productive suffix paradigm, the line-position entropy profile, the -am line-final enrichment, Stolfi's slot structure — all reproduced at consistent magnitudes. Several findings were more specific than prior work: the three-prefix system (qo- in B body text, o- in labels, cth- in A body text) with its stem-class selectivity, the nine-suffix productive paradigm in B, the cross-dialect cth- morpheme with its B-dialect suffix forms, and the onset self-succession patterns. The self-succession finding — that certain word-onset classes tend to follow themselves at 1.2-1.9× the rate expected by chance — is not clearly in the prior literature and became one of the central discriminating metrics in Phase 2.

The characterization phase ended with 30 candidate findings nominated for rigorous testing, drawn from the 175 quantitative results generated across all 169 experiments. These candidates were the ones with the strongest effect sizes and clearest theoretical implications, chosen post-hoc.

## 5. The Cryptanalyst Phase: Discrimination

Phase 2 designed and ran six experiments directly testing whether specific generation mechanisms could account for the characterization findings. The mechanisms tested were: the Greshko/Naibbe tarocchi homophonic cipher (exp_170), the Timm/Schinner self-citation algorithm (exp_171), cross-validation of all 30 candidate findings (exp_172), multiple testing correction (exp_173), slot-grammar residual analysis (exp_174), and long-range mutual information decay (exp_175).

An independent Opus review of the Phase 2 synthesis found two significant issues. First, the MI analysis had claimed that VMS shows "genuine long-range sequential structure" at lags 10-12. The review identified that at lags 11-12, within-line shuffled VMS produces higher MI than real VMS (VMS/within-shuffle ratios of 0.825 and 0.873), which rules out genuine structure — genuine long-range structure requires real > shuffle. This was a sampling artifact from short lines, not a signal. The claim was retracted. Second, the review found that the Timm falsification was based on a single parameter set (the published defaults) and the claim "no parameter setting can satisfy the joint constraints" was asserted without evidence. The review also flagged that the word ""FALSIFIED" was being used too loosely, that the cipher verdict should specify "position-blind ciphers" rather than ciphers in general, and that the position-sensitive cipher space was entirely untested.

Phase 3 addressed all of these. A Timm parameter sweep (exp_176) tested 75 parameter combinations across COPY_PROB × MODIFY_PROB × WINDOW and confirmed that 0 of 75 combinations approach the positional grammar metrics; the maximum -am LL enrichment achieved was 0.572× against a VMS value of 6.811×. A position-sensitive cipher simulation (exp_177) designed a three-table polyalphabetic cipher (separate LF/MID/LL substitution tables) calibrated against Latin clause-boundary morphology and found that it reaches 5.756× on -am LL enrichment — 84% of the VMS value — while completely failing on self-succession (producing ~1.0× versus VMS 1.465×). A critical post-hoc audit revealed that the LL table in this cipher was target-aware: it mapped all Latin clause-final morphemes to EVA -am specifically, rather than using a linguistically neutral mapping. This was documented as a significant limitation. An A-dialect Naibbe re-analysis (exp_178) confirmed that the positional grammar failure extends to A-dialect metrics (7 of 8 positional metrics fall outside Naibbe's confidence interval across all four simulation conditions). A hybrid cipher-copy simulation (exp_179) combined the position-sensitive cipher with a Timm-style copy buffer across 16 parameter combinations and found 0 of 16 viable: the copy component that raises self-succession proportionally dilutes the -am LL enrichment by replacing LL cipher-generated words with buffer copies, creating a structural trade-off that no parameter setting resolves.

The central result of Phases 2 and 3 is the dual constraint: Voynichese exhibits both position-sensitive onset-class grammar and sequential word-class memory, and no single tested generation mechanism produces both simultaneously. Position-blind ciphers produce neither. Position-sensitive substitution ciphers (even target-calibrated ones) produce position-sensitive grammar but not sequential memory. Self-citation algorithms produce some version of sequential memory but overshoot, and produce no positional grammar. Hybrid mechanical models cannot satisfy both constraints because the copy component that raises self-succession dilutes the positional specialization.

## 6. The Botanist Phase

The Botanist phase aims to match Voynich botanical illustrations against digitized medieval herbal manuscripts using visual embeddings. The hypothesis is that if VMS's botanical folios were drawn from or inspired by a specific herbal tradition, their nearest neighbors in a high-dimensional embedding space should cluster around manuscripts from that tradition. The null hypothesis is that VMS botanical illustrations are idiosyncratic and do not cluster near any specific known herbal.

The embedding model chosen is DINOv2 (facebook/dinov2-base, 768-dimensional CLS token vectors), a self-supervised vision transformer trained without labels that has shown strong performance on fine-grained visual similarity tasks. The four-pass strategy embeds each image four times: RGB full image, RGB cropped to above-ground portion (top 70% to remove roots), grayscale full image, and grayscale cropped. The motivation is that VMS pigments may not match comparandum pigments (ruling out color as a reliable feature), and VMS root illustrations are iconographically exaggerated (ruling out roots as a reliable feature). A candidate appearing in the top-30 nearest neighbors across multiple passes is more likely to be a genuine match than a single-pass result.

Days 1 and 2 of the planned five-day execution were completed. Day 1 downloaded the 209 VMS folios from Beinecke IIIF (1200px, IIIF v3), split three foldout panels, and verified DINOv2 running on Apple Silicon MPS at approximately 1.2 seconds per image. Day 2 downloaded the Manfredus de Monte Imperiali herbal (513 images from Gallica IIIF), a partial Vienna Dioscorides set (65 of 162 images from Wikimedia Commons), and a partial Carrara Herbal set (severely limited — the British Library IIIF API has been offline since a cyberattack in October 2023, yielding only 27 of 289 folios from Wikimedia). A VMS metadata classification script was written and executed, classifying 123 folios by illustration type (111 botanical, 7 pharmaceutical, 4 astronomical, 1 cosmological), plant count (88 single-plant, 23 multi-plant), and root style (93 realistic roots, 11 fantastical roots). Thirteen anomaly folios were flagged. Days 3-7 — the actual embedding extraction, nearest-neighbor search, synthesis, and visual spot-check — have not been run. The Botanist phase was interrupted by the Cryptanalyst's momentum and has produced no findings to date.

## 7. Meta-Review Findings

The process of having an independent Opus instance review Sonnet's synthesis documents produced substantive corrections in both reviews conducted so far. This matters for methodology documentation, not just for the specific corrections.

The Phase 2 review found: (1) The lags 10-12 MI claim was a sampling artifact — within-line shuffle exceeds real VMS at those lags, disconfirming genuine structure. This was the most significant factual error in the Phase 2 synthesis. (2) The Timm parameter sensitivity claim ("any parameter setting") was asserted without evidence; a parameter sweep was needed. (3) The word "FALSIFIED" was used loosely for results where the mechanism "fails on the tested parameters but might work on others." (4) The position-sensitive cipher space was entirely untested, leaving the cipher verdict underdetermined.

The Phase 3 review found: (1) The exp_177 position-sensitive cipher was target-aware in a way not disclosed in the original result — the LL table explicitly mapped all Latin clause-final morphemes to EVA -am, and the code comment labeled -am as "the target LL suffix." The primary agent had written this calibration into the script without flagging it as target-aware. (2) The -am LL metric is no longer the #1 decisive discriminator after exp_177 showed that a target-calibrated cipher reaches 84% of VMS; self-succession is now the metric that no tested mechanism reproduces. (3) The structured-grammar verdict needed to explicitly name the two remaining indistinguishable hypotheses rather than treating one as more supported than the other.

What this demonstrates about the methodology: the meta-review layer is not redundant with the primary agent's self-checking. In both cases, the reviewer found errors the primary agent did not flag in its own result write-ups. The errors were not random — they were systematic in the direction of overstatement, which is the expected failure mode for a production agent that has been running experiments and building toward a conclusion. An independent reviewer without context about the experimental history is better positioned to notice when a claim exceeds its evidence.

## 8. What's Been Established and What Hasn't

The strongest defensible claim is the dual constraint: Voynichese exhibits statistically robust position-sensitive onset-class grammar (-am LL enrichment of 6.811×, Bonferroni-corrected at p < 10⁻¹⁶¹; y-onset LF enrichment of 3.506×, p < 10⁻⁹⁰) and sequential word-class memory (onset self-succession of 1.465× mean, Bonferroni-corrected; qok→ch enrichment of 1.2-1.3×, surviving position control), and no single tested generation mechanism produces both simultaneously. This claim is supported by 400 Naibbe simulations, 1,500 Timm simulations across 75 parameter combinations, 300 position-sensitive cipher simulations, 800 hybrid cipher-copy simulations, cross-validation on random holdout splits, and multiple testing correction at both m=30 and m=175 thresholds.

The negative results individually are also established: position-blind homophonic ciphers of Latin or Italian (Naibbe) are inconsistent with VMS positional grammar across 400 simulations; Timm-style self-citation cannot jointly satisfy VMS self-succession and exact-word-repetition constraints at any tested parameter combination; simple templates are insufficient after onset-class position control; a hybrid mechanical architecture (position-sensitive cipher plus copy buffer) cannot satisfy both positional and sequential constraints simultaneously within the tested parameter grid.

What is explicitly not claimed: any decipherment or mapping of EVA tokens to natural language words; identification of a source language; discrimination among structured-grammar subtypes (constructed language, cipher of a morphologically unusual language, mnemonic system, ritual script); validity of these negative results against untested cipher mechanisms (transposition, running key, Polybius square, etc.); any claim about semantic organization or information content. The "structured grammar" verdict is a structural characterization — it means the writing system behaves as if governed by positional and sequential grammatical rules — not a claim about what the grammar encodes.

## 9. Open Questions and Immediate Next Steps

**Completing the Botanist phase** is the most obviously actionable next step. Days 3-7 of the planned execution remain: running the four-pass DINOv2 embeddings on VMS and herbal corpus images, computing nearest-neighbor lists, synthesizing per-folio candidate lists, and doing a visual spot-check of the top matches. The herbal corpus is partially downloaded; completing the Vienna Dioscorides download (65/162 images in hand) and finding an alternative to the unavailable British Library Carrara Herbal would strengthen the analysis. This phase could produce findings within a single focused session.

**A position-aware hybrid architecture** is the most important untested mechanism at this point. The exp_179 hybrid used position-blind copying (any recent word could be copied at any position). A hybrid that restricts copying to MID positions while applying the position-sensitive cipher exclusively at LF and LL could decouple the ss_mean and am_ll metrics. Testing whether this architecture can satisfy the dual constraint would either close the remaining cipher-mechanism gap or confirm that any satisfying architecture is functionally equivalent to a grammar.

**The methodology paper** is a plausible output at this stage. The dual-constraint result, the meta-review process, and the multi-phase agent architecture are all worth documenting in a form suitable for the Voynich research community. The negative results against Naibbe and Timm are specific enough to be directly useful to researchers evaluating those theories.

**A-dialect null simulations** remain incomplete. The exp_178 Naibbe A-dialect comparison was exploratory because Naibbe is a B-dialect cipher. A true A-dialect null simulation would require a cipher calibrated to Currier A statistics, which does not exist in published literature. Designing and testing such a cipher would complete the A-dialect coverage.

**Cross-phase synthesis** between the Librarian and Cryptanalyst is currently shallow — the Cryptanalyst used KB archives but did not query the KB's hypothesis graph for alternative theories to test. A structured query of the KB for position-sensitive cipher proposals and clause-boundary-morphology languages would help identify which untested hypothesis subspaces are most worth targeting.

## 10. Honest Assessment

What's novel about this work: the dual-constraint formulation — the specific claim that VMS simultaneously exhibits position-sensitive grammar and sequential word-class memory, and that no tested mechanical model satisfies both — is a cleaner and more specific negative result than anything in the published literature. Prior work has noted the line-ending -am enrichment (Stolfi's slot grammar touches it) and self-succession patterns (partly in the MI literature), but combining them into a single constraint that multiple mechanism classes independently fail on is new. The meta-review methodology — structured Opus review of Sonnet synthesis documents — is also a contribution to the "AI for scientific research" methodology question, and the Phase 2/3 interaction is a concrete example of where it added value. The hybrid cipher-copy experiment (exp_179) directly tests a hypothesis that is not in the published literature, even if the result is negative.

What's derivative: the characterization findings (experiments 1-169) mostly rediscovered established results. The -am LL enrichment, the Currier A/B split, the productive suffix paradigm, the word-length and positional entropy profiles — these are all in the prior literature. The experimental infrastructure is new but the findings are not, and a reader comparing this work to D'Imperio (1978), Stolfi (2000s), and recent Currier analyses will find substantial overlap in the characterization layer. The Naibbe and Timm simulations test existing proposals, not new ones. The novelty is in the systematic testing and the combination of results, not in any individual finding.

The realistic significance: this is computational Voynich research at a level of rigor that is uncommon in the field (which is dominated by unconstrained theorizing and confirmation-bias-driven analysis) but not unprecedented (Bowern and Lindemann's entropy work, Montemurro and Zanette's semantic network analysis, and a handful of others have similar methodological standards). The dual constraint is a small but genuine advance in theory discrimination. It doesn't solve the manuscript or identify what kind of system it is, but it does rule out a specific and important class of mechanism with more rigor than prior work, and it identifies precisely why: the two structural properties are jointly inconsistent with every mechanism that has been tested. That's the kind of progress that's realistic to make on a problem this hard.

The limitations the document doesn't fully capture: the corpus used (EVA ZL3b IVTFF) is not the only transcription and has known transcription errors; findings could shift with a cleaner or differently-defined transcription. The experiment count (179) sounds comprehensive but most experiments were exploratory characterization, not confirmatory hypothesis tests; the effective experimental power is lower than the count suggests. The VMS line-position grammar assumes that physical lines in the manuscript correspond to linguistic units, which is an assumption rather than an established fact — if scribes wrapped long linguistic sentences across physical lines, the positional grammar findings would require reinterpretation. And the project has not engaged seriously with the large body of informal Voynich research (forum communities, dedicated researchers outside academia) where some of the sharpest observation occurs; the Librarian KB is biased toward published and citable sources.
