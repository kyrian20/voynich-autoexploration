# Current State — Voynich Cryptanalyst
**Last updated**: 2026-04-10 (end of Phase 3, through exp_181)

After 181 experiments, the Voynich Cryptanalyst project has characterized two structural properties of Voynichese that together constrain the hypothesis space severely: words ending in "-am" appear at line endings roughly seven times more often than chance, and words of the same onset class tend to follow each other at about 1.5 times the baseline rate (self-succession). The project has tested five generation architectures against these constraints. Position-blind ciphers (Naibbe, Timm) fail entirely on the first property. A position-sensitive cipher with calibrated tables approaches the first property (5.756× vs 6.811×) but produces no self-succession. A position-blind hybrid cipher-copy also fails. A position-aware hybrid — copying restricted to mid-line positions only — protects the first property but originally appeared to fail the second due to a coupling between self-succession and exact-word repetition rate; however, an independent review identified that the modification operation used (replacing a copied word's onset) was maximally unfavorable to the hypothesis. When the modification was changed to preserve onset class and replace only the suffix, 4 of 36 parameter combinations passed all three viability thresholds simultaneously. These viable combinations still fall short of the manuscript's measured values on every metric (am_ll ~5.76 vs 6.81×; ss_mean 1.26-1.39 vs 1.465×; adj_rate 0.011-0.015 vs 0.009), and under manuscript-level thresholds none remain viable. The current state is: intrinsic grammatical structure remains the simplest uneliminated explanation, but the position-aware hybrid with onset-preserving modification is no longer categorically ruled out — it is an open question whether further parameter optimization or architectural changes can close the remaining gap to manuscript values.
