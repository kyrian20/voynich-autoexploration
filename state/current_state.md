# Current State — Voynich Cryptanalyst
**Last updated**: 2026-04-10 (end of Phase 3)

After 179 experiments across three phases, the Voynich Cryptanalyst project has established that the Voynich Manuscript's writing system has two structural properties that no tested generation mechanism can reproduce simultaneously: words ending in the suffix "-am" appear at line endings roughly seven times more often than chance would predict, and words of the same grammatical class tend to follow each other more often than chance — a pattern called self-succession — at a level of about 1.5 times the baseline rate. The first property rules out all "position-blind" cipher mechanisms tested, including the best available candidate (the Greshko/Naibbe tarot-deck cipher), which produces near-random positional distributions across 400 simulations; a deliberately calibrated position-sensitive cipher can approach but not reach the manuscript's value. The second property rules out all copy-based mechanisms tested (the Timm self-citation algorithm), which either underproduce or overproduce the pattern at any parameter setting, and is not reproduced at all by substitution ciphers. A hybrid model combining both mechanisms was tested across 16 parameter combinations and also failed to satisfy both properties simultaneously, because the copying that raises self-succession dilutes the line-ending specialization in exact proportion. The simplest explanation consistent with all the evidence is that Voynichese has intrinsic grammatical structure — rules specifying which word classes appear where on a line and which classes prefer to follow each other — though this does not establish that the manuscript encodes a natural language or that it can be deciphered.
